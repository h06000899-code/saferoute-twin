# SafeRoute Twin — 관악구 침수 대피 경로 (3D 디지털 트윈)

## 실행
1. zip을 먼저 압축 해제 → `index.html` 열기 (인터넷 필요: MapLibre, Esri 위성영상, OpenFreeMap 건물, AWS 지형 타일 — 모두 무료·키 불필요)

## 사용법
1. 상단에서 모드 선택 (실시간 재난 대응 / 가상 재난 시뮬레이션)
2. ① 위치 정하기: 현재 위치(GPS) / 예시 위치 / 3D 지도 클릭
3. ② 대피 경로 안내 시작
   - 지도: 빨강 = 일반 최단경로, 민트 = 침수 회피 안전경로, 번호 핀 = 구간별 안내 지점
   - 오른쪽: 구간별 안내 목록(📍 지도에서 위치 확인 → 해당 구간으로 이동·노란 강조), 두 경로 비교 카드·막대그래프
- 마우스: 드래그 이동, 우클릭(또는 Ctrl)+드래그 회전·기울기, 휠 확대/축소, 클릭으로 출발지 지정

## 실시간 기상 연동 (기상청 공공데이터포털)
1. data.go.kr에서 아래 두 서비스를 각각 '활용신청' (같은 인증키 하나로 사용, 승인까지 시간이 걸릴 수 있음)
   - 기상청_단기예보 조회서비스(15084084): 초단기실황·초단기예보·단기예보
   - 기상청_기상특보 조회서비스(15000415): 기상특보통보문
2. 실시간 모드 왼쪽 카드의 입력칸에 **Decoding 인증키**를 붙여넣고 '연동' 
3. 관악구 격자(nx=59, ny=125) 실황·예보 + 서울(stnId=109) 호우특보를 10분마다 갱신
- 위험도 입력 = 관측과 예보 중 큰 값(1시간/3시간), 서울 호우주의보 발효 시 위험도 최소 40점, 호우경보 최소 70점
- 일부 API가 실패해도 나머지로 동작하고, 전부 실패하면 수동 입력으로 전환

## 🤖 AI 침수 예측 (과거 데이터로 학습)
강우량이 정해지면 **학습된 모델이 침수 여부와 침수 구역을 예측**하고, 침수가 예측될 때만 대피 경로를 안내합니다. 침수 예측이 없으면 "침수 예측 없음"만 알려 주고 경로는 만들지 않습니다.

**1단계 — 침수가 발생하는가 (로지스틱 회귀, tools/train.py)**
- 학습 데이터: 서울 25개 구 × 2022년 365일 강우(10분 우량 → 일 최대 10분/1시간/3시간 누적) ↔ 2022 침수흔적도의 구·날짜별 침수 발생
- 라벨: 호우 기간(6/28~7/1, 8/8~9, 9/3~7)에 구 안에서 침수 폴리곤 3개 이상 → 침수. 보험·지원금 접수일 등 호우 기간 밖 기록은 제외, 1~2개뿐인 날은 애매해 제외
- 입력 log(1+강우) 3개, 계수 ≥ 0 제약(비가 많을수록 위험↑), 클래스 균형 가중. 임계값은 안전 목적상 재현율을 중시하는 F2로 선택
- 성능(학습에 쓰지 않은 구로 5-fold 교차검증): AUC 0.991, 재현율 0.78, 정밀도 0.37 (침수 날 41건뿐이라 정밀도는 낮음 → 재난 안내는 놓치지 않는 쪽을 택함)
- 화면의 "AI 침수 예측 점수"는 균형 가중 모델의 출력이라 실제 확률이 아니라 위험 지수입니다.

**2단계 — 어디가 침수되는가 (폴리곤별 임계값)**
- 관악구 2022 침수 폴리곤마다 "침수가 시작된 시각 직전 24시간 최대 모델 점수"를 임계값으로 학습 → 점수가 임계값 이상이면 그 폴리곤이 침수. 침수 시작 순서는 실제 발생 시각에서 학습하고, 확산 속도는 침수 면적 누적 비율로 고르게 보정(시각 미상 폴리곤은 알려진 분포에서 균등 배정)
- 2022.8.8 수준을 넘는 강우에서는 100년 빈도 침수 구역을 2022 침수 지점에서 가까운 순서로 추가(확장 폭 0.5는 가정값, 학습값 아님)
- 경로 탐색은 이 예측 침수 구역(침수 예측 구간 비용 ×16)을 피하는 다익스트라, 대피 지점도 예측 침수 구역 밖을 우선

**한계**: 학습 자료가 2022년 한 해(주로 8/8 호우)라 일반화에 한계가 있고, 실제 침수 깊이·배수 시설·지형은 반영하지 않는 교육용 규칙 기반 예측입니다.
재학습: `python tools/build.py` → `python tools/train.py` → `python tools/make_datajs.py` (원본 shp/csv 필요)

## 데이터
data.js = 원본 데이터(침수흔적도, 100년 빈도 침수지도, 도보 네트워크, DS_WAY 대피경로)에서 tools/build.py로 만든 관악구 경량 데이터.
지도: Esri 위성영상 + OpenStreetMap 기반 3D 건물(OpenFreeMap) + 지형(AWS Terrain). 침수 영역은 파랑(2022 실제) / 청록(예측) 반투명으로 건물 위에 표시. 도보망(회색·노랑·빨강)은 왼쪽 체크박스로 켤 수 있습니다.
위험도 = 0.3·(10분/25)+0.4·(1시간/100)+0.3·(3시간/150), 경로 비용 = 거리×(1+10×위험도×침수겹침), 다익스트라.
